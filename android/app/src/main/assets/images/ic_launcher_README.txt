应用安装图标说明

桌面图标资源：
  res/drawable/ic_launcher_background.xml   蓝色渐变底
  res/drawable/ic_launcher_foreground.xml   矢量熊猫 + 绿色语音角标
  res/mipmap-anydpi-v26/ic_launcher.xml     Android 8+ 自适应图标
  res/mipmap-*/ic_launcher.png              各密度位图（由设计稿导出）

设计稿源文件（1024×1024）：
  项目 assets/ic_launcher_abao.png

在 Android Studio 中替换图标：右键 res → New → Image Asset，或替换 mipmap 下 PNG。
